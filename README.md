# RobobenchWarehouse website

Static project page for RobobenchWarehouse, a simulation benchmark for robot foundation models on warehouse
picking. Served by GitHub Pages from this repository's `main` branch (root). No build step: `index.html` plus
`media/`.

The source of truth is `docs/payton/site/` on the `payton-dev` branch of the benchmark repository; this repository
is a published copy. To update it, copy `index.html` and `media/` from there, commit and push.
